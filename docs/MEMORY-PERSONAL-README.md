# 记忆工具 · 个人版

> 一个**跑在你电脑本地**的轻量记事本：随手记、随时找、改不坏、丢不了。AI 是可选加分项，默认关着。

---

## 一、一句话简介

**记忆工具 · 个人版**是一个本地运行的桌面记事本。你用它记灵感、待办、摘录、反复修改的文档……所有内容都只存在你自己的电脑里，**不上传、不采集、不需要账号**。

它只做好五件事：

1. **记得住** —— 随手记一条，秒存本地。
2. **找得到** —— 按关键词全文搜索，也能按「今天 / 本周 / 本月」回看。
3. **改不坏** —— 每次修改自动留一份历史版本，改错了随时回滚。
4. **丢不了** —— 一键备份到本地（或自选云端），删了也进回收站能恢复。
5. **可选 AI 帮忙** —— 想让 AI 帮你补全维度、总结一周、跑段代码？行，但**默认关闭，你说了算**。

## 四、隐私与 AI 控制

**一句话：默认关闭、数据不出机、你说了算。**

每个 AI 能力（增强 / 总结 / 提醒 / 代码执行）都**独立可配三档**：

| 档位 | 含义 | 数据流向 | 隐私 | 说明 |
|---|---|---|---|---|
| **关闭（默认）** | 不调用任何模型 | 数据不出机 | 🟢 最高 | 能力为空，UI 明示「未开启 AI」 |
| **本地模型** | 调用你本机的模型（如 Ollama） | 数据不出机 | 🟢 高 | 小模型总结 / 提取够用 |
| **外部模型** | 调用云端大模型（你自备 key） | 数据出机 | 🟡 低 | 能力最强，需你知情同意 |

选了「外部模型」后，还能再选**发送范围**：

| 发送范围 | 含义 |
|---|---|
| **全部** | 选中范围内的条目全文发送（效果最好，暴露最大） |
| **仅选中** | 只发你逐条勾选的条目，其余仅以「标题 + 去敏摘要」参与，支持字段级脱敏 |

再加三道保险：

- **一键全关 AI**：隐私控制中心顶部一个总开关，一键关闭所有 AI。
- **出机前二次确认**：任何数据要发出去前，都会明确告诉你「发到哪、多少字、含不含文件文本」，可取消。
- **编辑器常驻徽标**：写笔记时一眼看到当前状态（`AI 已关` / `🔒 本地` / `☁️ 外部·全部`）。

## 五、数据与存储

- **存哪**：全部在你电脑的本地数据目录，`JSON 分文件 + 原子写`，坏了可降级不丢。
- **资料仓库**：文件本体按内容指纹（SHA-256）收纳，相同内容自动去重；二进制文件抽出可搜索的纯文本缓存（搜索只搜文本，不发二进制）。
- **版本快照**：文本每次改存完整快照；文件按内容寻址去重。版本开关和保留数量你自选。
- **备份**：本地 / 云端你自选。本地省事占空间；云端省空间但要第三方、有泄露风险（会明确提示）。
- **清理提醒（三维度）**：任一命中就提醒你，**只建议、不自动删**：
  - 按版本数（如某条历史版本到 3 次、5 次）
  - 按空间（如占用到 1GB、2GB）
  - 按时间（如每隔 7 天、15 天、30 天）

## 六、典型使用场景

1. **记录今天的灵感**：快捷键唤起 → 写一句 → 存。晚上按「今天」回看。
2. **管理一份反复修改的文档**：拖进资料仓库，每次改完留版本，改坏了回滚到三天前。
3. **让 AI 总结本周记事**：勾选本周想总结的几条 → 点「总结」（外部模型 + 仅选中）→ 得到一份回顾，可设为提醒文案。
4. **记一段会算的代码**：把代码片段存成笔记 → 本地沙箱跑一下出结果，代码不出机。
5. **整理一段重要时段**：把某个项目的笔记归档进「2026-11 第 2 周」周期文件夹，事后好翻。

---

## 七、与 AI 的配合方式（都是可选项）

- **维度增强输入**：编辑器里点「补全维度」，AI 帮你补全可能漏掉的维度，你勾选 / 改 / 删后**追加**到正文，不静默改写你的原话。
- **AI 总结**：手动触发，总结你选中的范围，结果存本地。
- **AI 提醒**：提醒本体是本地托盘通知，AI 只帮你生成「提醒文案」。
- **代码执行**：本地 node:vm 沙箱，禁网络 / 文件 / 系统调用，超时自动杀掉，绝不影响主程序。

> 所有 AI 能力都**不影响你「不用 AI 也能正常记」**。不接任何模型，记事、搜索、版本、备份照样跑。

---

## 八、不做什么 / 边界

- **不做云同步（本轮）**：跨设备同步后置，本轮只留扩展点。先本地，后云端。
- **不做知识管理平台**：不是 Notion / Obsidian 级的东西——不上向量库、不做复杂工作流。
- **不自动采集**：不后台扫描、不自动总结、不自动回写，AI 只能「提议」、由你「采纳」。
- **不自动删除**：清理只建议、不自动删，删除都进回收站。
- **企业版专属，不在个人版**：团队 / 共享空间、权限 / 角色、审计日志、远端代码容器、云端后端——这些都是企业版功能，个人版没有。
